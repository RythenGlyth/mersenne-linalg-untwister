# Python Mersenne Twister State Recovery using Linear Algebra
This python script is designed to recover the internal state of the Mersenne Twister (MT19937) pseudo-random number generator using linear algebra techniques. The script can recover the state from a sequence of outputs generated by the MT19937 algorithm. It supports both full and partial outputs, allowing for flexibility in the recovery process.

It is inspired [symbolic_mersenne_cracker](https://github.com/icemonster/symbolic_mersenne_cracker) but aims to be faster by leveraging linear algebra methods instead of symbolic computation.

This has following benefits over other implementations:
- relatively fast (~30s regardless of the number of outputs involved)
- exceptionally fast for partial outputs (way faster than symbolic solvers)
- can recover state from partial outputs (can even have unknowns in between)
- doesn't require knowing the initial index of the generator (i.e. the number of outputs generated before the first output you have)

## Requirements
- SageMath (https://www.sagemath.org/)
- numpy (https://numpy.org/)
- scipy (https://www.scipy.org/)

## Installation
1. Install SageMath from the official website: https://www.sagemath.org/download.html and add the `sage` command to your PATH.
2. Install numpy and scipy using pip or other package managers. You can use the following command to install them via pip:
   ```bash
   pip install numpy scipy
   ```
3. Preparse the script using the following command:
   ```bash
   sage --preparse symbolic_mersenne_cracker.sage; mv symbolic_mersenne_cracker.sage.py symbolic_mersenne_cracker.py
   ```
4. You can now use the script in another Python script (see [examples](/examples))

## Usage
The library exports two Classes: `MersenneGF2` and `MersenneSolver`.
- `MersenneGF2` is a class that generates the two Mersenne linear functions `twist` and `temper` as GF(2) matrices.
  It cashes the resulting `twist_matrix` and `temper_matrix` for later in a file locally. This is why a first run may take a while longer. Generating the matrices can take up to 90 seconds.
- `MersenneSolver` is a class which provides a function `reverse_state_by_outputs` which takes the outputs of a Mersenne generator and returns a possible internal state of the generator (624 state integers and the next output's index).

### reverse_state_by_outputs
The `reverse_state_by_outputs` function in the `MersenneSolver` class is used to reverse the state of the Mersenne Twister given outputs, where some outputs might be fully known and others only partially known.

#### Arguments:
- `outputs`: A list where each element corresponds to a consecutive output slot. The length of this list, k, determines the final state index. Each element can be one of two types:
  - An `int`: Represents a fully known 32-bit output value (mask `0xFFFFFFFF`).
  - A `Tuple[int, int]`: Represents `(value, mask)` for a partially known output. `mask` indicates known bits (`1=known`, `0=unknown`).
- `initial_idx` (Defaults to `0`): The index of the first output in the list. If the index is wrong, the function returns a wrong state but the state will produce the same outputs as the actual state. <- this needs a proof
- `check_solution` (Defaults to `True`): If `True`, the function checks if the linear system is constrained enough. If the linear sysem is not constrained enough and `check_solution` is `True`, the function will raise an exception. If `False`, the function will return any state that could have produced the outputs.
  - Note: It is recommended to keep this as `True` for most cases, as it ensures the linear system is sufficiently constrained. However, if you are sure that the system is constrained enough (which is generally hard to predict), you can set it to `False` to avoid the check and thereby speed up the process.
- `verbose` (Defaults to `False`): If `True`, the function will print the progress and time taken for each step.

#### Returns:
A list of 625 integers representing the reconstructed internal state:
- `MT[0]...MT[623]` are the state vector.
- `MT[624]` is the index of the next value to be returned.

#### Example Usage:
```python
from symbolic_mersenne_cracker import MersenneSolver

solver = MersenneSolver()
outputs = [123456789, (987654321, 0xFFFF0000), 135792468]  # Example outputs
state = solver.reverse_state_by_outputs(outputs, initial_idx=0, check_solution=True, verbose=True)
print("Recovered state:", state)
```
